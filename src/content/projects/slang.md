## Problem and goal

Design a small language and write everything needed to run it, from the grammar to a virtual machine that executes the generated bytecode.

The language is statically typed and has integers, booleans and arrays; assignment, arithmetic, relational and logical operators with short-circuit evaluation; `if`/`else`, two kinds of loops; and functions with typed parameters and return types.

## Architecture and technical decisions

1. **Parsing** with an ANTLR grammar.
2. **AST construction.** A converter walks ANTLR's concrete syntax tree and builds our own typed AST, so later stages don't depend on generated classes.
3. **Type checking** of declarations, expressions and function calls before anything runs.
4. **Code generation** from the AST into bytecode, one container per function.
5. **A stack-based VM** that executes the bytecode.

## Challenges and how they were solved

- **Functions as values.** Functions are pushed onto the stack like any other value and called with an argument count, so the VM needs no special case for calls.
- **Variables from enclosing scopes.** The code generator records whether each captured variable is a local or an upvalue of the enclosing function, and the VM resolves upvalues at run time.
- **Short-circuit logic.** `||` and `&&` must skip the right side when the left side decides the result, which the generated bytecode handles with conditional jumps.
